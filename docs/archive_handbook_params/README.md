# Results with the handbook (SFPE) parameters

These reports are the results as they stood BEFORE the Improving-ML session (Sessions 1-9), when the simulator
used handbook values (free speed 1.25 m/s, Weidmann speed-density curve, door flow 1.3 persons/s/m) and smoke
did not slow walking. They are kept for comparison. The current reports in `docs/` use the parameters
calibrated on Juelich experiments (`docs/calibration.md`); switch back with `PARAM_SET = "sfpe"` in
`evac/config.py`. Raw runs: `results/archive_sfpe/`.
